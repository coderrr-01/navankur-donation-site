    About this project

    Navankur (meaning “sprout”) is a fictional foundation created for a GTU Societal Internship report. The site was built with HTML, CSS and JavaScript to practise forms, state handling and responsive layout, and it can be adapted for a real NGO later.

    Navankur Foundation is a demo. Data is saved only in this browser.
